# Nou Padel i Tenis Campos

Web del club **Nou Padel i Tenis Campos**, en Campos (Mallorca): horarios, tarifas, clases, carta de la
cafetería, anuncios y contacto, en castellano, catalán e inglés.

<https://noupadeliteniscampos.com>

Es una web estática generada con Python y Jinja2 a partir de ficheros JSON, y publicada en GitHub
Pages. La documentación técnica está en [`docs/`](docs/README.md).
